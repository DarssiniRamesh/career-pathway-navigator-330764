This prototype demonstrates the end-to-end UX: onboarding questionnaire → AI-style recommendations with explanations → career detail pages → learning roadmap with progress → resume/portfolio checklists → job application tracker → saved careers → profile/account → admin CMS → analytics.

Tip: Use the left navigation to jump around, or follow the guided CTAs. This is a single HTML file with embedded CSS/JS (no backend required).

    Prototype notes

    This single HTML file is designed to demonstrate the complete Career Navigator UX end-to-end: onboarding, recommendations with explanations, career details, roadmaps and progress, checklists, job tracker, saved careers, account/profile, admin CMS, and analytics.

    How to use:
    1. Start at Sign up / Login and log in.
    2. Complete Onboarding and submit.
    3. Review Recommendations, open a career, and generate a Roadmap.
    4. Update Checklists and add items in Job Tracker.
    5. Explore Admin CMS and Analytics to see system-wide dashboards.
    File location: career_navigator_frontend/public/ux-prototype.html — open directly in a browser, or serve via the dev server and visit /ux-prototype.html.
